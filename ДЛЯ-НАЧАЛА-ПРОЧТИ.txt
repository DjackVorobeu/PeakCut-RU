PeakCut на русском — что установлено и как пользоваться
=====================================================

Папка программы:  F:\peakcut
Ярлык:            на Рабочем столе, называется PeakCut
Адрес программы:  http://127.0.0.1:8765


ЗАПУСК
------
1. Двойной щелчок по ярлыку PeakCut на Рабочем столе.
2. Через 5–20 секунд сам откроется браузер — это и есть программа.
3. Вход не нужен.

ОСТАНОВКА
---------
Закрыть вкладку браузера недостаточно: сервер работает в фоне.
Остановить: F:\peakcut\Stop-PeakCut.cmd (двойной щелчок).


РУССКИЙ ЯЗЫК
------------
Интерфейс переведён на русский.

Русская речь: модель распознавания GigaAM v2 (231 МБ) уже скачана.
Чтобы резать русское видео:
1. Добавьте видео (ссылка или файл).
2. В строке добавления нажмите «Настройки» и выберите язык «Русский —
   в списке языков (там же есть English и Arabic).
3. Нажмите «Сделать клипы».

Субтитры на клипах будут кириллицей, шрифтом, в котором есть русские буквы.
Заголовки, хуки и описания ИИ тоже пишет по-русски (если в видео русская речь).
У автора (Creators -> автор -> Настройка) язык можно задать один раз, тогда
он применяется к его видео и записям стримов.

Что ещё осталось на английском: часть служебных подписей в карточках видео,
редкие диалоги (редактор клипа, обновление версии), страница /admin и
служебные сообщения сервера. Основные экраны — главная, все видео,
настройки (ИИ, распознавание речи, хранилище) — на русском.


ПЕРВЫЙ ШАГ: КЛЮЧ ИИ
-------------------
В настройках ИИ ключ уже сохранён (Gemini, модель gemini-2.5-flash).
Если понадобится свой: Настройки -> ИИ -> выбрать сервис -> вставить ключ ->
«Найти модели» -> «Сохранить и проверить».
Без ключа клипы выбираются по громкости.


КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Вставьте ссылку на YouTube / Twitch / Kick или загрузите файл.
2. PeakCut скачает видео, распознает речь на этом компьютере (аудио никуда
   не отправляется) и найдёт яркие моменты.
3. Каждый момент режется в 9:16, получает субтитры слово-в-слово и хук.
4. Клипы лежат в F:\peakcut\data (кнопка «Открыть папку» в Настройки -> Хранилище).
5. Стримы: авторы добавляются в разделе «Авторы», PeakCut может писать эфир
   и нарезать клипы во время стрима.
6. Публикация в YouTube / Instagram / TikTok: Настройки -> Приложения.


ГДЕ ЧТО ЛЕЖИТ
-------------
F:\peakcut\                 программа
F:\peakcut\data\            видео, клипы, база, настройки, модели речи
F:\peakcut\bin\             ffmpeg.exe, ffprobe.exe, значок
F:\peakcut\.venv\           окружение Python (не трогать)


ОБНОВЛЕНИЕ
----------
Русский перевод и поддержка русской речи внесены прямо в код в F:\peakcut,
они сохранены отдельным коммитом git ("Russian interface and Russian speech").
1. Остановите программу (Stop-PeakCut.cmd).
2. В командной строке:
      cd /d F:\peakcut
      git pull --rebase
      .venv\Scripts\python.exe -m pip install -r requirements.txt
3. Запустите ярлыком.
Если после обновления с GitHub русский интерфейс пропал или появились
конфликты — верните локальную версию файлов: git checkout -- web/index.html studio
(это сотрёт только правки перевода, данные и клипы не тронутся).


УДАЛЕНИЕ
--------
1. Остановите программу.
2. Удалите F:\peakcut и ярлык PeakCut с рабочего стола.
3. При желании удалите Python 3.12 в «Параметры -> Приложения».


ЧТО УСТАНОВЛЕНО
---------------
- Python 3.12.10 (в профиль пользователя)
- ffmpeg и ffprobe — F:\peakcut\bin
- зависимости PeakCut — F:\peakcut\.venv
- модели речи: английская Parakeet (~630 МБ) и русская GigaAM v2 (~231 МБ)
  в F:\peakcut\data\models
- шрифты для субтитров с кириллицей: Montserrat ExtraBold и Russo One
