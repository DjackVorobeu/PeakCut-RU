# PeakCut на русском — установка и описание

Это доработанная копия [PeakCut](https://github.com/haziqahmedqasmi/PeakCut) — открытой программы, которая
делает вертикальные клипы с субтитрами из длинных видео и стримов. Здесь добавлены русский интерфейс и
распознавание русской речи.

## Что добавлено по сравнению с оригиналом

1. **Русское распознавание речи.** Модель [GigaAM v2](https://github.com/salute-developers/GigaAM) от Сбера,
   конвертированная в формат sherpa-onnx (NeMo transducer), скачивается из того же хранилища моделей, что и
   английская. Работает локально: звук не покидает компьютер. Добавлена строка в `MODELS` и параметр
   `PEAKCUT_ASR_MODEL_RU`; модель просит 64 мел-канала, поэтому у каждой модели теперь свой `feature_dim`.
2. **Кириллица в субтитрах.** В шрифтах PeakCut (Anton, Archivo Black, Poppins) нет русских букв, и программа
   раньше переводила русские слова в латиницу («Привет» → «Privet»). Добавлены Montserrat ExtraBold и
   Russo One с полной кириллицей, а для клипов с русской речью шрифт подставляется автоматически.
3. **Русские заголовки и хуки.** Если речь в видео русская, ИИ пишет хук, заголовок, описание и хештеги по-русски.
4. **Русский интерфейс.** Переведены главный экран, боковое меню, все разделы настроек (ИИ, распознавание речи,
   хранилище, профиль, безопасность, приложения), предупреждения и подсказки.
5. **Понятное сообщение об ошибке ИИ.** Google отвечает «User location is not supported», когда Gemini недоступен
   из страны пользователя; теперь PeakCut говорит об этом прямо и подсказывает, что делать, вместо «модель
   устарела».

## Установка

Нужны Windows 10/11 и интернет на время установки. Права администратора не нужны.

1. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте, либо склонируйте:
   `git clone https://github.com/<ваш-логин>/<имя-репозитория> C:\peakcut`
2. В папке запустите **Install-PeakCut.cmd** (или в PowerShell: `powershell -ExecutionPolicy Bypass -File install.ps1`).

Установщик сам:
- проверит и при необходимости поставит Python 3.12 в профиль пользователя;
- скачает ffmpeg и ffprobe в папку `bin`;
- создаст окружение `.venv` и поставит зависимости;
- скачает модели речи: английскую (~630 МБ) и русскую (~231 МБ);
- соберёт `PeakCut.exe`, положит ярлык на Рабочий стол.

Потом программа запускается двойным щелчком по ярлыку и открывается в браузере на `http://127.0.0.1:8765`.

Куда ставить — выбранная вами постоянная папка с коротким путём (`C:\peakcut`). Не ставьте в глубокие пути:
Windows не грузит модель речи, если полный путь к файлу длиннее 260 символов.

## Как пользоваться

1. Вставьте ссылку на YouTube / Twitch / Kick или загрузите файл.
2. В «Настройках» добавления видео выберите язык — для русской речи «Русский».
3. Нажмите «Сделать клипы». Готовые клипы лежат в `data`, кнопка открытия — Настройки → Хранилище.

Ключ ИИ задаётся в Настройки → ИИ. Поддерживаются Gemini, OpenAI, Grok, Groq, OpenRouter, Claude,
локальная Ollama и любой OpenAI-совместимый сервис. Без ключа клипы выбираются по громкости.

## Обновление и удаление

- Обновить: остановить программу (`Stop-PeakCut.cmd`), затем `git pull --rebase` и
  `.venv\Scripts\python.exe -m pip install -r requirements.txt`.
- Удалить: остановить программу, удалить папку и ярлык. Python 3.12 можно снять в «Параметры → Приложения».

## Проверки

Встроенные тесты (`python tests/run.py`) проходят полностью; две проверки обновлены под новое поведение
(русские буквы остаются кириллицей, языков стало три).
